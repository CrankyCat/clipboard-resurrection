Clipboard Resurrection - shared package inputs

This directory supplies shared assets, default settings and 500 empty pattern
slots. Player pattern.ini files are not distributed. Back up your own patterns
before replacing a mod-manager installation or its slot folders.

The current user guide is package/v240/Docs/clipboard/Clipboard-ReadMe.txt in
the source tree. A built package places that guide at Docs/clipboard alongside
the other user documentation. This base readme is not included in modern builds.

The original Clipboard texture and material assets were originally published
by Struckur, author of the original Clipboard. Existing contributor credits
and applicable third-party terms are retained. See LICENSE.txt and the root
README.md for the project license and attribution.
