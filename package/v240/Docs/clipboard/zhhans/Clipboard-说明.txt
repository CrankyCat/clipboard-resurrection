Clipboard Resurrection 3.0.0

Clipboard 可将成组的聚落对象复制为可重复使用的蓝图。选择对象并保存蓝图后，即可根据 Clipboard 工具的位置和旋转角度进行粘贴。你也可以移动、旋转、缩放或拆解选中的对象。

安装

Fallout 4 的 OG、NG 和 AE 版本使用同一个 Clipboard 安装包。请安装与你当前游戏运行时版本匹配的 F4SE，以及必需的 Runtime Database，后者提供 Data\F4SE\Plugins\f4rd-runtime.bin。请通过 f4se_loader.exe 启动游戏。

F4SE: https://f4se.silverlock.org/
Runtime Database: https://www.nexusmods.com/fallout4/mods/108394

使用模组管理器安装完整安装包，并启用 Clipboard.esp。请将包内的 DLL、脚本、Strings 和 Interface 文件配套安装。如果从使用 ClipboardExtension.dll 的旧安装包升级，请禁用旧 DLL，确保只有 Data\F4SE\Plugins\clipboard.dll 处于启用状态。替换现有安装前，请备份你的蓝图。

模组配置菜单（MCM）提供 Clipboard 的选项和快捷键。未安装 MCM 时，可在 Data\MCM\Settings\clipboard.ini 中对应的 INI 节下覆盖设置。手动修改 INI 后，请重启游戏。
MCM: https://www.nexusmods.com/fallout4/mods/21497

入门指南

1. 在工房的“特殊”类别中建造 Clipboard 工具。
2. 激活工具的控制界面，选择一种选择方式：全部、长方体、球体、圆柱体、按区块、按插件，或使用手动选择枪。
3. 选中所需对象，然后将其保存到蓝图槽位。确认覆盖会替换该槽位的内容；取消则保留原有蓝图。
4. 将工具放置在目标位置，选择已保存的蓝图进行粘贴。工具的位置和旋转角度决定这组对象出现的位置和朝向。
5. 等待导入完成后再开始其他操作。请查看有关对象、线路或电力未能完成准备工作的所有警告。

共有 500 个槽位。安装包提供的槽位均为空。蓝图文件保存在 Data\F4SE\Plugins\Clipboard\<slot>\pattern.ini。重新安装或替换槽位文件夹前，请备份你自己的蓝图文件。

文本和数字输入

Clipboard 自带输入菜单，无需 TIM。按 Enter 确认，按 Tab 或 Escape 取消。也可以使用鼠标按钮及手柄屏幕键盘；请参照输入框下方显示的操作提示。请将 Interface/ClipboardInput.swf 与匹配的 DLL 和脚本配套安装。请直接键入内容：目前不支持从 Windows 剪贴板粘贴。

MCM 选项“输入时隐藏 Condition Boy/Girl”默认开启。安装该模组后，Clipboard 会在输入界面打开期间暂时隐藏其叠加显示界面，随后恢复被其更改的显示状态。无需安装额外模组。

旋转、缩放与还原

旋转角度须大于 0 且不超过 180 度，最多可保留六位小数。请使用英文句点作为小数点，例如 12.345678。你可以选择围绕选区中心或 Clipboard 工具旋转。

“增大”和“缩小”接受相对变化的百分比。“增大”的输入值须大于 0 且不超过 1000；“缩小”的输入值须大于 0 且不超过 99。输入值最多可保留六位小数，但变化后每个对象的尺寸都必须精确等于其原始尺寸的 1% 至 1000% 之间的某个整数百分比。格式有效的数字仍可能不适用于所选对象的尺寸。Clipboard 会在更改对象之前拒绝该数值，并显示有效的步长、限值或邻近数值。

例如，将尺寸为 100% 的对象增大 12%，其尺寸会变为 112%。将尺寸为 50% / 100% / 150% 的混合对象组增大 2%，结果为 51% / 102% / 153%；增大 1% 则会被拒绝，因为部分结果会是非整数百分比。小数变化量也可能有效：将尺寸为 200% 的对象增大 0.5%，其尺寸会变为 201%。

整体缩放会同时改变对象的大小和间距。单独缩放只改变对象大小，保持位置不变。两种模式使用相同的大小限制；对于被拒绝的调整，Clipboard 不会擅自取整或将其限制到允许的边界值。

两种还原操作都会将所有选中对象的大小精确设为 100%。单独还原会保持所有位置不变。整体还原在选中对象的缩放比例不同时也会保持位置不变；如果缩放比例全都相同，则会按该比例的倒数调整间距。缩放比例已经全为 100% 的对象组不会移动。还原并不是撤销历史操作，也无法恢复不同缩放比例的对象组先前的间距。

材料消耗

材料支付默认关闭。如果希望粘贴时消耗建造材料，请在 MCM 中启用此功能。材料消耗根据导入规则允许导入的对象及其可用建造配方计算；允许导入但没有配方的对象不会产生配方材料消耗。

检查材料消耗时，会先查看当前工房容器。如果其中每种所需材料都足够，Clipboard 就可以直接显示这些本地数量，无需搜索相连的聚落和玩家物品栏。只读的材料消耗视图还提供了可选的所有来源总量查询。否则，Clipboard 会检查所有来源，并相应标注总量。查看材料消耗不代表授权支付材料。

启用材料支付后，Clipboard 会请求确认，在提示结束后再次检查材料是否足够，并在放置对象前核实材料扣除情况。材料会依次从当前工房、相连的工房、玩家物品栏中扣除。如果无法完成或核实支付，放置就会停止。已经扣除的资源不会自动退还。

蓝图与导入

蓝图会保存对象类型、位置、旋转角度、缩放比例和内部电线，也会记录与选区外现有对象之间符合条件的电线连接。这些外部对象不会被复制。重新连接它们需要工具位于原始位置，且原始端点仍然有效；将工具移到新地点后，这些外部连接会被忽略。玩家创建的端点仅适用于其所在的存档。详情请参阅 Clipboard-对象选择与导入.txt。

蓝图不会保留容器内的物品、武器或护甲改装、所有权或脚本状态。SS2 地块的规划、等级和居民也不会保存。如果所需的插件或对象不可用，Clipboard 会用瓶盖作为占位对象。连接到缺失或被过滤的待放置对象的电线会被跳过。

如果现有对象的基础对象、位置、旋转角度和缩放比例与蓝图中的放置记录一致，Clipboard 就会复用该对象，避免再创建一个副本，并可将现有对象用于电线连接。仅当因重复而跳过的数量大于零时，才会显示此数量，即使禁用了导入警告也一样。

“启用负载限制”默认开启，用于限制对象放置的工作量和同时进行的工房初始化调用数量。关闭它可能导致脚本系统过载，引发 Papyrus 堆栈转储，干扰 Sim Settlements 2 等其他模组。完成状态检查仍会保持启用，关闭负载限制也不一定能缩短导入时间。启用负载限制进行放置时，每十秒会重复显示一次“Clipboard: 正在导入对象...”。无论是否启用负载限制，初始化和通电阶段都会显示进度百分比。这些百分比表示已完成的工作量，而不是已用时间；请等待最终结果。

准备或初始化失败的对象不会参与后续的接线和通电处理；成功的对象则可以继续。如果 Clipboard 无法核实完成状态，例如发生超时或中断，整个导入过程的接线和通电处理都会停止。

选择/导出与光源导入各有独立的选项。导入的非角色对象默认会禁用 Havok 物理，以让松散对象保持原位；脚本、动画和工房操作仍可移动它们。有关这些控制选项和可选模组过滤器的说明，请参阅 Clipboard-对象选择与导入.txt。

如果你可能回退到旧版本，请保留升级前的存档。
旧版 Clipboard DLL 无法恢复以新 3.0.0 格式保存的操作。

Clipboard 使用游戏当前的语言。有关语言选择和故障排查，请参阅 Clipboard-语言.txt；近期变更请参阅 更新日志.txt。

帮助与制作人员

即使关闭“启用诊断日志”，警告、错误和构建标识仍会记录到 Clipboard.log 中。如果需要更详细的信息，请先在 MCM 中启用此选项，再重现问题。报告问题时，请提供执行的操作、游戏版本、设置以及 Documents\My Games\Fallout4\F4SE\Clipboard.log；如有 Papyrus.0.log，也请一并提供。重启游戏前请复制 Clipboard.log：每次启动都会用新日志替换它。
