Clipboard Resurrection 3.0.0

Clipboard 可將聚落中的一組物件複製成可重複使用的藍圖。選取物件並儲存藍圖後，即可根據 Clipboard 工具的位置及旋轉角度貼上。你也可以移動、旋轉、縮放或拆解選取的物件。

安裝

Fallout 4 的 OG、NG 和 AE 版本皆使用相同的 Clipboard 套件。請安裝與目前遊戲執行版本相符的 F4SE 版本，以及必要的 Runtime Database，後者提供 Data\F4SE\Plugins\f4rd-runtime.bin。請透過 f4se_loader.exe 啟動遊戲。

F4SE: https://f4se.silverlock.org/
Runtime Database: https://www.nexusmods.com/fallout4/mods/108394

請使用模組管理器安裝完整套件，並啟用 Clipboard.esp。隨附的 DLL、指令碼、Strings 和 Interface 檔案必須一併保留。若從使用 ClipboardExtension.dll 的套件更新，請停用該舊版 DLL，確保只有 Data\F4SE\Plugins\clipboard.dll 處於啟用狀態。覆蓋現有安裝之前，請先備份你的藍圖。

模組設定選單（MCM）提供 Clipboard 的選項與快捷鍵。若未使用 MCM，可在 Data\MCM\Settings\clipboard.ini 中對應的 INI 區段內覆寫設定。手動修改 INI 後，請重新啟動遊戲。
MCM: https://www.nexusmods.com/fallout4/mods/21497

開始使用

1. 在工房的「特殊」類別中建造 Clipboard 工具。
2. 啟動工具的控制介面，選擇選取方式：全部、方盒、球體、圓柱、依區塊、依插件，或使用手動選取槍。
3. 選取所需物件，然後將它們儲存至藍圖欄位。確認覆寫會取代該欄位的內容；取消則會保留現有藍圖。
4. 將工具放置於目的地，並選擇已儲存的藍圖來貼上。工具的位置與旋轉角度決定整組物件出現的位置及方向。
5. 等待匯入完成後，再開始其他操作。請詳閱任何關於物件、電線或電力無法完成準備的警告。

共有 500 個欄位。套件提供的欄位皆為空白。藍圖檔案儲存於 Data\F4SE\Plugins\Clipboard\<slot>\pattern.ini。重新安裝或取代欄位資料夾之前，請先備份自己的藍圖檔案。

文字與數字輸入

Clipboard 內建輸入選單，不需要 TIM。按 Enter 確認，或按 Tab 或 Escape 取消。也可使用滑鼠按鈕與可透過控制器操作的螢幕鍵盤；請依照輸入欄位下方顯示的操作提示。請將 Interface/ClipboardInput.swf 與相符的 DLL 和指令碼一併安裝並保留。請直接鍵入數值：目前不支援從 Windows 剪貼簿貼上。

MCM 的「輸入時隱藏 Condition Boy/Girl」選項預設為開啟。若已安裝該模組，Clipboard 會在輸入介面開啟時暫時隱藏其疊加顯示，並於結束後還原它所變更的顯示狀態。不需要額外安裝其他模組。

旋轉、縮放與還原

旋轉角度必須大於 0 度且不超過 180 度，最多可輸入六位小數。請使用半形句點作為小數點，例如 12.345678。你可以選擇以選取物件的中心或 Clipboard 工具為旋轉中心。

「放大」與「縮小」採用相對百分比變化量。「放大」接受大於 0 且不超過 1000 的數值；「縮小」接受大於 0 且不超過 99 的數值。最多可輸入六位小數，但變更後每個物件的大小都必須恰為其原始大小的 1% 至 1000% 之間的整數百分比。格式有效的數值仍可能不適用於選取物件的大小。Clipboard 會在變更物件前拒絕該數值，並顯示可用的增減幅度、限制或鄰近數值。

例如，將大小為 100% 的物件放大 12%，會變成 112%。將大小混合為 50% / 100% / 150% 的一組物件放大 2%，會得到 51% / 102% / 153%；放大 1% 則會被拒絕，因為部分結果會出現非整數百分比。小數變化量也可能有效：將大小為 200% 的物件放大 0.5%，會變成 201%。

整體縮放會同時改變物件大小與間距。個別縮放則只改變物件大小，保留其位置。兩種模式使用相同的大小限制；Clipboard 不會在變更遭拒時，暗中將數值四捨五入或限制在允許範圍內。

兩種還原操作都會將每個選取物件的大小精確設為 100%。個別還原會保留所有位置。整體還原在所選物件的縮放比例不同時，也會保留位置；若所有物件的縮放比例相同，則會依該共同縮放比例的倒數調整間距。已全部為 100% 的物件群組不會移動。還原並非復原歷程功能，也無法恢復先前不同縮放比例物件之間的間距。

材料需求

預設不會扣除材料。若希望貼上時消耗建造材料，請在 MCM 中啟用此功能。材料需求依匯入規則允許的物件及其可用建造配方計算；允許匯入但沒有配方的物件，不會產生配方材料需求。

檢查材料需求時，會先查看目前的工房容器。如果其中每種所需材料都足夠，Clipboard 就能直接顯示當地數量，不必搜尋相連聚落與玩家的物品欄。唯讀的材料需求檢視也提供選項，可查看所有來源的總量。否則，Clipboard 會檢查所有來源，並據此標示總量。查看材料需求並不代表授權扣除材料。

啟用材料扣除後，Clipboard 會要求確認，在提示結束後再次檢查材料是否足夠，並在放置物件前核實扣除結果。材料會依序從目前的工房、相連工房及玩家物品欄取用。如果無法完成或核實材料扣除，便會停止放置。已扣除的資源不會自動退還。

藍圖與匯入

藍圖會儲存物件類型、位置、旋轉角度、縮放比例與內部電線，也會記錄與選取範圍外既有物件之間符合條件的電線連接。這些外部物件不會被複製。重新連接需要工具位於原始位置，且原始端點仍然有效；將工具移至新目的地時，會忽略這些外部連接。玩家建立的端點僅適用於其所屬存檔。詳情請參閱 Clipboard-物件選取與匯入.txt。

藍圖不會保留容器內容物、武器或護甲改裝、所有權或指令碼狀態。SS2 的地塊規劃、等級與居民也不會儲存。若所需的外掛檔案或物件無法使用，Clipboard 會以瓶蓋作為替代物。連接至缺失或被篩選掉的放置物件的電線將會略過。

若既有物件的基礎物件、位置、旋轉角度與縮放比例都符合藍圖中的放置資料，Clipboard 就會重複利用該物件。這可避免建立另一個副本，也能使用既有物件連接電線。因重複而略過的數量只會在大於零時顯示，即使已停用匯入警告也會顯示。

「啟用負載限制」預設為開啟。此功能會限制物件放置的工作量，以及同時進行的工房初始化呼叫數量。關閉此功能可能導致指令碼處理超載，並造成 Papyrus 堆疊傾印，干擾 Sim Settlements 2 等其他模組。完成狀態檢查仍會持續運作，而關閉負載限制也不一定能縮短匯入時間。啟用負載限制時，放置過程中每隔 10 秒會重複顯示「Clipboard: 正在匯入物件...」。無論使用哪種模式，初始化與供電過程都會顯示進度百分比。這些數值表示已完成的工作量，而非經過的時間；請等待最終結果。

準備或初始化失敗的物件，不會參與後續的電線連接與供電作業；成功的物件則可繼續處理。如果 Clipboard 無法核實完成狀態，例如逾時或中斷後，整次匯入的電線連接與供電作業都會停止。

選取／匯出與光源匯入各有獨立選項。匯入的非角色物件預設會停用 Havok 物理效果，讓鬆散物件留在原位；指令碼、動畫與工房操作仍可移動它們。關於這些控制選項與可選的模組篩選器，請參閱 Clipboard-物件選取與匯入.txt。

如果你可能改回使用舊版本，請保留升級前的存檔。
舊版 Clipboard DLL 無法繼續以新版 3.0.0 格式儲存的作業。

Clipboard 會使用遊戲的語言。如需語言選項與疑難排解資訊，請參閱 Clipboard-語言.txt；如需近期變更，請參閱 變更記錄.txt。

說明與製作人員

即使關閉「啟用診斷日誌」，警告、錯誤及組建識別資訊仍會記錄在 Clipboard.log 中。若需要更詳細的資訊，請先在 MCM 中開啟此選項，再重現問題。回報時請提供執行的動作、遊戲版本、設定，以及 Documents\My Games\Fallout4\F4SE\Clipboard.log；若有 Papyrus.0.log，也請一併提供。重新啟動遊戲前，請先複製 Clipboard.log：每次啟動都會以新記錄取代此檔案。
