Clipboard Resurrection－變更記錄

3.0.0

- Fallout 4 OG、NG 及 AE 共用同一套件，搭配相符的 F4SE 及外部 Runtime Database 使用；包含十二種語言的遊戲內文字。
- 提供專用的文字與數值輸入選單，無須 TIM，支援鍵盤、滑鼠及控制器操作，並可選擇在開啟輸入介面時隱藏 Condition Boy/Girl。
- 旋轉與縮放輸入最多支援小數點後六位。匯出及匯入時，藍圖中的數值會保留其儲存值的精確度。
- 除非變更後每個物件的尺寸都是 1% 至 1000% 範圍內的整數百分比，否則不允許相對縮放變更，並會提供有效變更的指引。
- 兩種還原操作皆會將所有物件設為 100%。個別還原會保留位置；整體還原會調整縮放比例一致之群組的間距，並保留混合尺寸群組的位置。
- 優先檢查當地工房的材料，在成本檢視中提供所有來源的總量，並減少重複查詢配方及物品欄所需的處理。支付材料時仍會要求確認、重新檢查可用數量，並驗證材料已移除。
- 匯出時會納入手動選取的物件；若匯出取消、內容為空或未通過驗證，則保留原有藍圖。
- 記錄連接至複製選取範圍外既有物件的合格電線，且僅在工具位於原始位置、端點有效時重新連接。
- 改善跨聚落區塊的選取，移除大量區塊／外掛檔物件選取及物件摧毀操作中僅處理前 128 個物件的截斷限制，並減少重複的選取搜尋及變換計算。
- 新增獨立控制選項，分別用於放寬物件選取／匯出資格、匯入光源，以及匯入物件的物理效果。改善 SS2 及 Auto Beds 篩選條件，排除已識別的自動生成內容，同時允許符合資格的根物件及獨立物件；邊界大小為零的啟動器與可移動靜態物件仍會排除。
- 改善大量物件的匯入，在略過物件時保留電線端點，重新連接相接的導管，並重複利用符合條件的既有物件配置。
- 佈線及電力處理前，會等待必要的工房初始化完成。個別物件失敗後，已驗證的物件仍可繼續處理；若無法確定是否完成，則停止整次匯入的佈線及電力處理。「啟用負載限制」預設為開啟。
- 定期顯示放置通知，並以百分比顯示初始化及電力處理進度。僅在因重複而略過的數量大於零時顯示該數量。
- 修正工房回呼參數、通電物件清理、選取框清理、分頁及 MCM 設定路由。移除暫時性的效能分析工具。
- 一律記錄警告、錯誤及組建識別資訊。可選擇啟用診斷日誌以加入詳細資訊；每次啟動遊戲時，Clipboard.log 都會重新開始記錄。
- 提供 500 個空白藍圖欄位，並保留對現有藍圖及設定的支援。更新 Docs/clipboard 中的英文使用者指南。
