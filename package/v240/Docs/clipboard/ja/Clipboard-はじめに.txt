Clipboard Resurrection 3.0.0

Clipboardは居住地のオブジェクト群をコピーし、再利用できるパターンとして保存します。オブジェクトを選択してパターンを保存すると、Clipboardツールの位置と回転を基準に貼り付けられます。選択したオブジェクトの移動、回転、拡大・縮小、解体も可能です。

インストール

Fallout 4のOG、NG、AEでは、同じClipboardパッケージを使用します。インストール済みのランタイムに対応するF4SEビルドと、必須のRuntime Databaseをインストールしてください。後者にはData\F4SE\Plugins\f4rd-runtime.binが含まれています。ゲームはf4se_loader.exeから起動してください。

F4SE: https://f4se.silverlock.org/
Runtime Database: https://www.nexusmods.com/fallout4/mods/108394

MODマネージャーでパッケージ全体をインストールし、Clipboard.espを有効にしてください。同梱のDLL、スクリプト、StringsおよびInterfaceのファイルは、すべて一緒に導入してください。ClipboardExtension.dllを使用していたパッケージから更新する場合は、古いDLLを無効にし、Data\F4SE\Plugins\clipboard.dllだけが有効になるようにしてください。既存のインストールを置き換える前に、パターンをバックアップしてください。

Mod Configuration Menu（MCM）でClipboardのオプションやホットキーを設定できます。MCMがなくても、Data\MCM\Settings\clipboard.iniの対応するINIセクションで設定を上書きできます。INIを手動で変更した後は、ゲームを再起動してください。
MCM: https://www.nexusmods.com/fallout4/mods/21497

はじめに

1. ワークショップの「特殊」カテゴリーからClipboardツールを作成します。
2. ツールの操作メニューを開き、選択方法を選びます。全選択、ボックス、球、円柱、セル別、プラグイン別、または手動選択銃が使用できます。
3. 必要なオブジェクトを選択し、パターンスロットに保存します。上書きを確定するとそのスロットの内容が置き換わり、キャンセルすると既存のパターンが保持されます。
4. 貼り付け先にツールを置き、保存済みのパターンを選んで貼り付けます。オブジェクト群の配置は、ツールの位置と回転によって決まります。
5. 別の操作を始める前に、インポートが完了するまでお待ちください。オブジェクト、ワイヤー、電力の準備ができなかったという警告が表示された場合は、内容を確認してください。

スロットは500個あります。パッケージには空のスロットが用意されています。パターンファイルはData\F4SE\Plugins\Clipboard\<slot>\pattern.iniに保存されます。再インストールやスロットフォルダーの置き換えを行う前に、自分のパターンファイルをバックアップしてください。

文字と数値の入力

Clipboardには専用の入力メニューがあり、TIMは不要です。Enterで確定、TabまたはEscapeでキャンセルできます。マウスでのボタン操作や、コントローラー用の画面キーボードも使用できます。入力欄の下に表示される操作案内に従ってください。Interface/ClipboardInput.swfは、対応するDLLおよびスクリプトと一緒にインストールしておいてください。値は直接入力してください。現在、Windowsのクリップボードからの貼り付けには対応していません。

MCMの「入力中はCondition Boy/Girlを非表示」オプションは、初期設定でオンになっています。そのMODがインストールされている場合、Clipboardは入力画面を開いている間、そのオーバーレイを一時的に非表示にし、終了後に変更した表示状態を元に戻します。追加のMODは必要ありません。

回転、拡大・縮小、復元

回転角度には、0度より大きく180度以下の値を、小数点以下6桁まで入力できます。小数点にはドットを使用してください（例：12.345678）。回転の中心は、選択範囲の中心またはClipboardツールから選べます。

「拡大」と「縮小」には、現在のサイズに対する相対的な変化量をパーセントで入力します。拡大は0より大きく1000以下、縮小は0より大きく99以下の値を指定できます。小数点以下6桁まで入力できますが、変更後の各オブジェクトのサイズは、元のサイズの1%から1000%の範囲で、端数のない整数のパーセント値になる必要があります。入力形式が正しい数値でも、選択したオブジェクトのサイズには適用できない場合があります。その場合、Clipboardはオブジェクトを変更する前に入力を拒否し、使用可能な刻み幅、上限・下限、または近い値を表示します。

たとえば、サイズが100%のオブジェクトを12%拡大すると112%になります。50% / 100% / 150%が混在するグループを2%拡大すると、51% / 102% / 153%になります。1%の拡大は、一部の結果に端数が生じるため拒否されます。小数の変化量でも有効な場合があります。200%のオブジェクトを0.5%拡大すると201%になります。

全体の拡大縮小は、オブジェクトのサイズと間隔を同時に変更します。個別の拡大縮小は、位置を維持したままオブジェクトのサイズを変更します。どちらのモードにも同じサイズ制限が適用されます。Clipboardは、拒否された変更を通知なしに丸めたり、制限値に収めたりすることはありません。

どちらの復元操作も、選択したすべてのオブジェクトのサイズを正確に100%に設定します。個別の復元では、すべての位置が維持されます。全体の復元でも、選択したオブジェクトのサイズが異なる場合は位置が維持されます。すべて同じサイズの場合は、その共通の倍率の逆数で間隔を調整します。すでに100%のグループは移動しません。復元は操作履歴を元に戻す機能ではなく、サイズが混在したグループの以前の間隔を復元するものではありません。

必要な素材

素材の消費はデフォルトで無効です。貼り付け時に建築資材を消費させるには、MCMで有効にしてください。必要な素材は、インポート規則で許可されたオブジェクトについて、利用可能な建築レシピに基づいて算出されます。許可されたオブジェクトでもレシピがなければ、レシピに基づく素材は消費しません。

必要な素材の確認では、まず現在のワークショップのコンテナを調べます。必要な素材がすべて足りている場合、Clipboardは接続された居住地やプレイヤーの所持品を検索せずに、その場の保有数を表示できます。閲覧専用の素材確認画面では、任意で全供給元の合計を表示することもできます。素材が足りない場合、Clipboardはすべての供給元を調べ、合計の対象範囲を明示します。必要な素材を確認するだけでは、消費を承認したことにはなりません。

素材の消費を有効にすると、Clipboardは承認を求め、確認画面の後に素材が足りているか再確認し、取り出しを検証してからオブジェクトを配置します。現在のワークショップ、接続されたワークショップ、プレイヤーの所持品の順に使用します。素材の消費を完了できない、または検証できない場合、配置は停止します。すでに取り出された資源は自動では返還されません。

パターンとインポート

パターンには、オブジェクトの種類、位置、回転、拡大率、および内部のワイヤーが保存されます。また、選択範囲外の既存オブジェクトへのワイヤー接続も、条件を満たすものは記録されます。範囲外のオブジェクト自体はコピーされません。再接続するには、ツールが元の場所にあり、元の接続先が有効である必要があります。ツールを別の場所へ移動すると、これらの外部接続は無視されます。プレイヤーが作成した接続先は、そのセーブデータ固有のものです。詳細はClipboard-オブジェクトの選択とインポート.txtを参照してください。

パターンには、コンテナの中身、武器や防具の改造、所有権、スクリプトの状態は保存されません。SS2の区画プラン、レベル、入植者も保存されません。必要なプラグインまたはオブジェクトが利用できない場合、Clipboardは代替としてボトルキャップを使用します。配置対象が欠落しているかフィルターで除外されている場合、それに接続されたワイヤーはスキップされます。

Clipboardは、ベースオブジェクト、位置、回転、拡大率がパターンの配置情報と一致する既存オブジェクトを再利用します。これにより重複したコピーの作成を避け、既存オブジェクトをワイヤーの接続にも利用できます。重複によりスキップされた数は、0より大きい場合にのみ表示されます。これはインポート警告を無効にしていても表示されます。

「負荷制限を使用」はデフォルトで有効です。配置処理と、同時に実行するワークショップ初期化呼び出しの数を制限します。無効にするとスクリプト処理に過負荷がかかり、Papyrusのスタックダンプが発生して、Sim Settlements 2など他のMODに支障をきたすおそれがあります。完了確認は引き続き行われるため、無効にしてもインポート時間が短くなるとは限りません。スロットリングを使用した配置中は、「Clipboard: オブジェクトをインポート中...」が10秒ごとに繰り返し表示されます。初期化と電力の有効化では、どちらのモードでも進行状況がパーセントで表示されます。これは経過時間ではなく、完了した処理の割合を示します。最終結果が出るまでお待ちください。

準備または初期化に失敗したオブジェクトは、その後の配線と電力処理から除外されます。成功したオブジェクトの処理は続行できます。タイムアウトや中断の後など、Clipboardが完了を検証できない場合は、そのインポート全体の配線と電力処理が停止します。

選択・エクスポートと光源のインポートには、それぞれ別の設定があります。インポートしたアクター以外のオブジェクトは、固定されていないものが動かないよう、デフォルトでHavok物理が無効になります。ただし、スクリプト、アニメーション、ワークショップの操作によって動くことはあります。これらの設定と任意のMODフィルターについては、Clipboard-オブジェクトの選択とインポート.txtを参照してください。

旧バージョンに戻す可能性がある場合は、アップグレード前のセーブを残しておいてください。
古いClipboard DLLでは、新しい3.0.0形式で保存された処理を再開できません。

Clipboardはゲームの言語設定に従います。言語の選択とトラブルシューティングについてはClipboard-言語.txtを、最近の変更については変更履歴.txtを参照してください。

ヘルプとクレジット

「診断ログを有効化」がオフでも、警告、エラー、ビルド識別情報はClipboard.logに記録されます。詳しい情報が必要な場合は、問題を再現する前にMCMでオンにしてください。報告には、実行した操作、ゲームのバージョン、設定、およびDocuments\My Games\Fallout4\F4SE\Clipboard.logを含めてください。Papyrus.0.logがある場合は、それも含めてください。ゲームを再起動する前にClipboard.logをコピーしてください。起動するたびに新しいログで置き換えられます。
