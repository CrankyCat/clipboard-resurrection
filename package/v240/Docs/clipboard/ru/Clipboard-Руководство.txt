Clipboard Resurrection 3.0.0

Clipboard копирует группы объектов поселения в многоразовые шаблоны. Выделите объекты, сохраните шаблон, а затем вставьте его с учётом положения и поворота инструмента Clipboard. Выделенную группу также можно перемещать, поворачивать, масштабировать или разбирать.

УСТАНОВКА

Для Fallout 4 OG, NG и AE используется один и тот же пакет Clipboard. Установите версию F4SE, соответствующую установленной версии игры, а также необходимую Runtime Database, которая предоставляет файл Data\F4SE\Plugins\f4rd-runtime.bin. Запускайте игру через f4se_loader.exe.

F4SE: https://f4se.silverlock.org/
Runtime Database: https://www.nexusmods.com/fallout4/mods/108394

Установите полный пакет через менеджер модов и включите Clipboard.esp. Не разделяйте входящие в пакет DLL, скрипты, файлы Strings и Interface. Если вы обновляете пакет, в котором использовался ClipboardExtension.dll, отключите эту старую DLL, чтобы активным остался только Data\F4SE\Plugins\clipboard.dll. Перед заменой установленной версии сохраните резервные копии своих шаблонов.

Mod Configuration Menu (MCM) предоставляет настройки и горячие клавиши Clipboard. Без MCM настройки можно переопределить в Data\MCM\Settings\clipboard.ini, указав их в соответствующих разделах INI. После изменения INI вручную перезапустите игру.
MCM: https://www.nexusmods.com/fallout4/mods/21497

НАЧАЛО РАБОТЫ

1. Создайте инструмент Clipboard в категории «Особое» меню мастерской.
2. Активируйте его элементы управления и выберите способ выделения: «Все», «Параллелепипед», «Сфера», «Цилиндр», «По ячейке», «По плагину» или ручное выделение оружием.
3. Выделите нужные объекты и сохраните их в слот шаблона. Подтверждение перезаписи заменит содержимое слота; отмена сохранит существующий шаблон.
4. Разместите инструмент в нужном месте и выберите сохранённый шаблон для вставки. Положение и поворот инструмента определяют, где появится группа.
5. Дождитесь завершения импорта, прежде чем начинать другую операцию. Обратите внимание на предупреждения об объектах, проводах или электропитании, которые не удалось подготовить.

Доступно 500 слотов. В комплекте они пустые. Файлы шаблонов хранятся по пути Data\F4SE\Plugins\Clipboard\<slot>\pattern.ini. Перед переустановкой или заменой папок слотов сохраните резервные копии своих файлов шаблонов.

ВВОД ТЕКСТА И ЧИСЕЛ

В Clipboard есть собственное меню ввода; TIM не требуется. Нажмите Enter для подтверждения или Tab либо Escape для отмены. Также доступны кнопки мыши и экранная клавиатура для контроллера; следуйте подсказкам под полем ввода. Файл Interface/ClipboardInput.swf должен быть установлен вместе с соответствующими DLL и скриптами. Вводите значения вручную: вставка из буфера обмена Windows пока не поддерживается.

Параметр MCM «Скрывать Condition Boy/Girl при вводе» включён по умолчанию. Если этот мод установлен, Clipboard временно скрывает его интерфейс во время ввода, а затем восстанавливает изменённое состояние видимости. Дополнительные моды не требуются.

ПОВОРОТ, МАСШТАБИРОВАНИЕ И ВОССТАНОВЛЕНИЕ

Для поворота укажите угол больше 0 и не больше 180 градусов, допускается до шести знаков после десятичного разделителя. В качестве разделителя используйте точку, например 12.345678. Выберите, вокруг чего поворачивать объекты: центра выделения или инструмента Clipboard.

Для увеличения и уменьшения указывается относительное изменение в процентах. При увеличении допустимо значение больше 0 и не больше 1000, при уменьшении — больше 0 и не больше 99. Допускается до шести знаков после десятичного разделителя, но итоговый размер каждого объекта должен составлять целое число процентов от исходного размера в пределах от 1% до 1000%. Даже допустимое число может не подходить для размеров выделенных объектов. Clipboard отклонит его до изменения объектов и покажет допустимые шаги, пределы или близкие значения.

Например, увеличение объектов размером 100% на 12% даст размер 112%. Увеличение группы с размерами 50% / 100% / 150% на 2% даст 51% / 102% / 153%; увеличение на 1% будет отклонено, поскольку некоторые результаты окажутся дробными. Дробные изменения тоже могут быть допустимы: увеличение объекта размером 200% на 0.5% даст 201%.

Общее масштабирование меняет и размеры объектов, и расстояния между ними. Индивидуальное масштабирование меняет размеры объектов, сохраняя их положения. В обоих режимах действуют одинаковые ограничения размера; Clipboard не округляет и не ограничивает отклонённое изменение без предупреждения.

Оба действия восстановления устанавливают размер каждого выделенного объекта ровно на 100%. Индивидуальное восстановление сохраняет все положения. Общее восстановление тоже сохраняет положения, если размеры выделенных объектов различаются; если все размеры одинаковы, оно меняет расстояния между объектами обратно пропорционально их общему масштабу. Группа объектов размером 100% не перемещается. Восстановление — не история отмены: оно не вернёт прежние расстояния в группе объектов с разными размерами.

ЗАТРАТЫ КОМПОНЕНТОВ

По умолчанию расход компонентов отключён. Включите его в MCM, если при вставке должны тратиться строительные материалы. Затраты рассчитываются по доступным рецептам строительства для объектов, разрешённых правилами импорта. Если для разрешённого объекта нет рецепта, затраты компонентов по рецепту для него отсутствуют.

При проверке затрат сначала учитываются материалы в контейнере текущей мастерской. Если их хватает на всё необходимое, Clipboard может показать количество местных материалов без поиска в связанных поселениях и инвентаре игрока. В окне просмотра затрат, которое ничего не списывает, можно дополнительно запросить общий итог по всем источникам. Если местных материалов не хватает, Clipboard проверяет все источники и соответствующим образом обозначает итоговые количества. Просмотр затрат не означает согласия на списание материалов.

Когда расход компонентов включён, Clipboard запрашивает подтверждение, после него повторно проверяет наличие материалов и перед размещением объектов проверяет их списание. Сначала используются материалы текущей мастерской, затем связанных мастерских, затем инвентаря игрока. Если списание не удаётся завершить или проверить, размещение прекращается. Уже списанные ресурсы автоматически не возвращаются.

ШАБЛОНЫ И ИМПОРТ

Шаблоны сохраняют типы объектов, их положение, поворот, масштаб и провода между ними. Также записываются подходящие соединения с существующими объектами за пределами выделения. Сами внешние объекты не копируются. Для восстановления этих соединений инструмент должен находиться на исходном месте, а исходные точки подключения — оставаться пригодными; при перемещении инструмента в новое место внешние соединения игнорируются. Точки подключения, созданные игроком, привязаны к конкретному сохранению. Подробности см. в Clipboard-Выделение-и-импорт-объектов.txt.

Шаблоны не сохраняют содержимое контейнеров, модификации оружия и брони, принадлежность объектов и состояние скриптов. Планы участков, уровни и поселенцы SS2 не сохраняются. Если необходимый плагин или объект недоступен, Clipboard подставляет вместо него крышку. Провода, подключённые к отсутствующим или отфильтрованным при размещении объектам, пропускаются.

Clipboard использует существующий объект повторно, если его базовый объект, положение, поворот и масштаб совпадают с размещением по шаблону. Это позволяет не создавать ещё одну копию и использовать существующий объект для подключения проводов. Число пропущенных дубликатов показывается, только если оно больше нуля, даже при отключённых предупреждениях об импорте.

Параметр «Ограничивать нагрузку» включён по умолчанию. Он ограничивает объём работы при размещении и число одновременных вызовов инициализации мастерской. Если его отключить, скриптовая система может оказаться перегружена, а дампы стека Papyrus — помешать работе других модов, например Sim Settlements 2. Проверки завершения останутся активными, и отключение ограничения не обязательно ускорит импорт. При размещении с ограничением нагрузки сообщение «Clipboard: Импорт объектов...» повторяется каждые десять секунд. Ход инициализации и подачи питания в обоих режимах показывается в процентах. Эти показатели отражают выполненную работу, а не прошедшее время; дождитесь окончательного результата.

Объекты, подготовка или инициализация которых завершилась ошибкой, исключаются из последующего подключения проводов и подачи питания; работа с успешно обработанными объектами может продолжаться. Если Clipboard не может подтвердить завершение работы, например после превышения времени ожидания или прерывания, подключение проводов и подача питания прекращаются для всего импорта.

Для выделения и экспорта объектов и для импорта источников света предусмотрены отдельные настройки. По умолчанию у импортированных объектов, кроме актёров, отключается физика Havok, чтобы незакреплённые предметы оставались на месте; скрипты, анимации и действия мастерской по-прежнему могут их перемещать. Описание этих настроек и дополнительных фильтров модов см. в Clipboard-Выделение-и-импорт-объектов.txt.

Если вы можете вернуться к старой версии, сохраните сохранение, сделанное до обновления. Старые DLL-файлы Clipboard не могут возобновить операции, сохранённые в новом формате 3.0.0.

Clipboard использует язык игры. О выборе языка и устранении неполадок читайте в Clipboard-Языки.txt, а о недавних изменениях — в Журнал-изменений.txt.

ПОМОЩЬ И БЛАГОДАРНОСТИ

Предупреждения, ошибки и идентификаторы сборок записываются в Clipboard.log, даже если параметр «Включить диагностический журнал» отключён. Если нужны дополнительные сведения, включите его в MCM до повторного воспроизведения проблемы. Укажите выполненное действие, версию игры и настройки, приложите Documents\My Games\Fallout4\F4SE\Clipboard.log, а при наличии — Papyrus.0.log. Скопируйте Clipboard.log до перезапуска игры: при каждом запуске он заменяется новым журналом.
