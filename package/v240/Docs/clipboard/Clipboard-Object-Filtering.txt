Clipboard Resurrection 3.0.0 - Object selection and import

SELECTION AND EXPORT

By default, automatic selection requires an object created during play and
linked to a workshop. Lights also need nonzero object bounds and a workshop
construction recipe. Manual selection is independent of this automatic filter.

The MCM option "Allow Normally Filtered Objects To Be Selected And Exported"
is off by default and broadens automatic selection. Export honors the current
selection, including manually selected objects, regardless of this option.
Permanent exclusions and invalid-object checks still apply. An export with
zero eligible objects does not create or overwrite a pattern.

Neither permissive option bypasses Clipboard's infrastructure protections,
configured blacklists, or checks for invalid objects. Settlement workbenches,
Clipboard helpers, objects with the IsMarker flag, and unsupported actor types
remain excluded. Activators (ACTI) and movable statics (MSTT) whose object bounds
are all zero are also always excluded, including from old patterns. This is a
base-object rule, not a hardcoded crop-helper list. The light-source option does
not bypass it. Wire connections are handled separately from object selection.

SELECTION AREA

Box, Sphere and Cylinder use their chosen volume. By Plugin selects from the
chosen source plugin. By Cell offers Clipboard Tool's Cell or Workshop's Cells.
Workshop's Cells covers cells assigned to the current settlement and matching
workshop-linked objects. The tool-cell option covers only its single cell.

By Cell and By Plugin limit objects stored in the exterior persistent cell to
5,000 units from the tool by default. Ordinary settlement cells have no distance
cutoff. The user setting is [Selection] fWideSelectionMaxDistance. Permissive
selection does not change the chosen area or this distance limit.

Clear an old selection when comparing settings: selection messages count newly
added objects. Some plugin-placed objects lack an individual highlight even
when selected. A pattern's plugin list also includes dependencies such as its
workshop and cell; it is not just a list of selected objects' source plugins.

WIRES TO EXISTING OBJECTS

Export records wires between selected objects and eligible connections to
existing objects outside the selection. Outside endpoints can be plugin-placed
or player-created. They are not added to the copied object list, moved, or
recreated when the pattern is pasted.

External connections are used only when the Clipboard tool is in the recorded
source cell at its original export position. Rotating the tool alone does not
change this rule. At a different destination, external connections are ignored
and internal wires still import normally. Missing, moved or mismatched original
endpoints are skipped; Clipboard does not search for a nearby replacement.

Player-created outside endpoints belong to the save containing those objects.
Their connections are not portable to another playthrough. Re-export an older
pattern to capture external connections that its original file did not record.

IMPORT AND PHYSICS

MCM's Import Options contains these controls:

- "Allow normally filtered light sources to be imported" is off by default.
  Enable it to admit lights without object bounds or a workshop recipe.
- "Disable Havok Physics On Imported Objects" is on by default. It keeps
  imported non-actors from immediately falling or rolling and restores their
  placement if physics moved them during loading. Turn it off for normal loose
  object physics. It does not prevent scripted movement, animation, activation,
  or workshop manipulation, and does not apply this physics change to actors.
- "Use Throttling" is on by default. It limits placement work and simultaneous
  workshop initialization calls. Off may overload scripting and cause Papyrus
  stack dumps that interfere with other mods such as Sim Settlements 2. The
  next import uses the new setting; completion checks remain active in both modes.

Import cannot recover an object's original placement history from a pattern.
Most non-light objects saved with permissive selection can therefore be pasted
with the light-source import option off. Component costs follow the same import
filter; an admitted object without a recipe has no recipe component cost.

Patterns preserve base objects and transforms, not inventories, attached weapon
or armor modifications, or script state. Modified equipment pastes as its
default base object. Missing forms use bottlecap placeholders. Skipping an
object or one of its wires does not shift the other wire connections. Matching
existing objects are reused by base object, position, rotation and scale; new
wires can connect to them without duplicating their placement. Failed or unready
objects are excluded individually when the remaining work is verified complete.
Uncertain completion stops wiring and power for the whole import.

OPTIONAL MOD FILTERS

The default filters allow otherwise-eligible SS2 plot roots and standalone
objects while excluding objects marked PlotSpawnedKeyword or PreventExport,
SS2 static collections (SCOL), and children linked from supported Auto Beds
parents. These rules apply to all selection methods and export, including
permissive selection. They do not reconstruct SS2 plans or other mod state,
and do not apply to imported pattern rows.

These controls are INI-only. Use [OptionalFiltering] in
Data\MCM\Settings\clipboard.ini to override the packaged defaults:

- aReferenceKeywordBlackList: reference keywords to exclude.
- aCollectionPluginFamilyBlackList: plugins whose static collections are
  excluded, including active plugins that directly require them as masters.
- aChildParentScripts and aChildLinkKeywordBlackList: parent script types and
  slot-link keywords used together to identify generated children.

See Data\MCM\Config\Clipboard\settings.ini for the supplied lists. Keyword
entries use PluginName#decimalLocalFormID, without a load-order prefix. A missing
setting uses its default; an explicitly empty value disables that rule.
Unavailable optional mods are skipped. Restart the game after INI changes.

Unconditional plugin/form blacklists remain in [Selection]: aPluginBlackList,
aMasterPluginBlackList and aFormBlackList. User lists replace each setting's
defaults. If an older user INI still lists SS2.esm or its expansions in the
plugin blacklist, or SS2.esm in the master blacklist, remove those entries to
use the optional SS2 filters while keeping any other exclusions you want.
The packaged unconditional defaults still exclude Sim Settlements and Seasons.

Old bEnableToolCellObjectSelection and bEnableWorkshopCellObjectSelection
settings are ignored. Existing import and physics preferences keep their INI
sections: bAllowAllObjectsToBeImported in [Selection] and
bDisableHavokOnImportedObjects in [Balance]. Use Throttling is bUseThrottling
in [Import]. Retired profiling and lock-trace settings are ignored.
